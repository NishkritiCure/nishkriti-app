# Parity fixture artifact

The backend (Python engine) produces `engine-fixtures-v{n}.json.zip` — a set
of `{ input, expected_output }` pairs generated by running the Python engine
over canonical inputs. The TS fallback engine must produce byte-identical
output (per APP-ENGINE-CONTEXT.md §18) against the same inputs.

## How to wire up

1. Download the artifact from the backend CI run for the pinned engine
   version (or mount it via a submodule once backend CI publishes one).
2. Point `ENGINE_PARITY_ARTIFACT` at the extracted JSON file before running:

   ```bash
   ENGINE_PARITY_ARTIFACT=/path/to/engine-fixtures-v1.json \
     pnpm vitest run src/engine/__tests__/integration/parity.test.ts
   ```

3. The parity test will iterate every fixture and fail CI on any drift.
